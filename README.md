Overview
The File and Folder Organization Bot is a Robotic Process Automation (RPA) solution developed using UiPath Studio to automate file and folder management. The bot scans a source directory, classifies files based on predefined rules such as file type, extension, naming conventions, and other criteria, and automatically moves them into appropriate folders.

Key Features:
- Automated file detection and classification
- Rule-based file sorting and organization
- Dynamic folder creation
- Automated file movement
- Duplicate file handling
- Exception and error handling
- Execution logging and monitoring
- Support for large volumes of files
- Manual and scheduled execution capabilities

Testing:
The automation workflow was tested and validated using unit testing, integration testing, and performance testing to verify file organization, error handling, and reliable execution.

Technologies Used:
- UiPath Studio
- UiPath Robot
- UiPath Orchestrator
- RPA
- .NET Framework
- Windows

Project Workflow
1. Select the source directory
2. Retrieve files from the directory
3. Identify file properties
4. Apply predefined organization rules
5. Create destination folders when required
6. Move files to the appropriate folders
7. Handle errors and exceptions
8. Generate execution logs
